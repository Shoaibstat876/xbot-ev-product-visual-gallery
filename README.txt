XBOT EV - Supporting Concept Visuals
Candidate: Muhammad Shoaib Abdul Shakoor

This package contains AI-generated concept visuals prepared as supplementary
material for the XBOT EV assessment. The images illustrate a consistent visual
direction across multiple viewing angles.

Tools Used:
These visuals were created and refined using Adobe Illustrator, Adobe Photoshop,
Canva, and AI-assisted image-generation and editing tools. Adobe Illustrator was
used for vector and branding elements, Adobe Photoshop for image refinement and
composition, Canva for layout and presentation, and AI tools for generating and
enhancing the product-view concepts.

These visuals are not verified official product photographs. Product design,
branding details, specifications, and small printed text should be confirmed
against official XBOT EV source material before commercial use.
